# Frontend

The frontend is the browser-based workspace for the Inventory Management System. It provides the dashboard and screens for point of sale, inventory, transactions, announcements, and branch operations. It is built with React, TypeScript, and Vite, and uses Auth0 for sign-in.

For frontend environment variables, local setup, Docker, and deployment, see the [frontend setup guide](../docs/README.md#3-configure-the-frontend). For the project overview and screenshots, see the [main README](../README.md).
